Microphone Spectrum Analyzer

A real-time audio frequency analyzer running entirely in your web browser.

Getting Started

If you are using a laptop or mobile device, it should have a microphone built in. If you are using a Desktop computer, you may need to connect a microphone. If you already have a webcam with a built in microphone, that should be sufficient.

To start the spectrum analyzer, simply click on th ebutton labeled 'Start Spectrum Analyzer'. The analyzer will display the audio spectrum in real time from approximately 20 Hz to 20 kHz, using a logarithmic frequency scale that more closely matches human hearing.
